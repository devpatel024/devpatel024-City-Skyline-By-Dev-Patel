## 🚀 Quick Start

> [!TIP]
> **Zero installation required!** `skyline_architect_made_by_dev_patel.html` is a single, self-contained HTML5 application powered by **Three.js r128**, **Tailwind CSS 3.4**, **Lucide Icons**, and the **Web Audio API** — no npm, no bundler, and no backend server needed.

```bash
git clone https://github.com/devpatel024/City-Skyline-By-Dev-Patel.git
cd City-Skyline-By-Dev-Patel
```

1. **▶️ Launch instantly:** Open the [**live GitHub Pages version**](https://devpatel024.github.io/City-Skyline-By-Dev-Patel/skyline_architect_made_by_dev_patel.html), or double-click `skyline_architect_made_by_dev_patel.html` in Chrome, Edge, Firefox, or Safari. Prefer a local server? Run `python3 -m http.server 8080` and open `http://localhost:8080/skyline_architect_made_by_dev_patel.html`.
2. **🌍 Configure your world:** Choose from **6 procedural biomes**, **4 architectural themes**, and optional toggles for **Unlock All / Sandbox Mode** ($5M + all tech unlocked), **Fast 8-Step Interactive Walkthrough**, and **Dynamic Natural Disasters**.
3. **🔐 Exclusive Creator Vault:** Authorized creators can open the password-protected **Super Admin Vault** from the Title Screen button (or press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd>) to access the **God-Mode Console** and **5 pre-built iconic cities**.

## 💰 6-Step Beginner's Guide — Build a Thriving Metropolis

1. **🛣️ Connect to the Highway:** Start beside the north Highway Outside Connection using **2-Lane Road** or **Auto-Grid** (or stamp a Cloverleaf interchange). Every road automatically carries underground power cables, water mains, and sewage pipes.
2. **⚡ Power & Water:** Open **Services** and place 1 **Wind Turbine** (or Solar Plant) and 1 **Water Pump**. Press <kbd>U</kbd> or <kbd>I</kbd> to verify glowing underground utilities.
3. **🏗️ Zone & Watch 4-Stage Construction:** Open **Zones** and paint 🟢 Residential, 🔵 Commercial, 🟠 Industrial (place downwind!), 🟣 Office, and 🟡 Luxury Estates to watch foundations, steel girders, rotating 3D tower cranes, and PBR buildings rise.
4. **📈 Master Economy & Taxes:** Open **Economy**, keep taxes around **9%–11%**, balance RCI Demand, and place Parks & Schools so buildings level up (**L1 → L5**) for higher hourly revenue. Place the **World Stock Exchange** to unlock live Bull Booms and Billionaire Philanthropy Grants.
5. **⛽ Add Modular Services, Transit & City Life:** Click any Service building to attach visible 3D Modular Upgrades, link Bus/Metro stops to slash congestion, and add Petrol Pumps, EV Superchargers, Supercar Dealerships, and Grand Malls.
6. **🌍 Expand Across 49 Map Tiles:** Reaching Milestones awards Cash Grants, Dev Tree Points, and free Map Tile Permits (<kbd>T</kbd>) to build International & Private Airports, Seaports, Intercity Rail, Signature Landmarks, and Billionaires' Row towers.

## ⚙️ Engine Architecture, Performance & Blueprints

- **⚡ 60 FPS Instanced Architecture:** Decoupled 30Hz fixed-timestep simulation loop paired with pooled `THREE.InstancedMesh` rendering for buildings, trees, vehicles, spinning wheels, articulated pedestrians, and tower cranes.
- **🎚️ Graphics & LOD Presets (Settings):** Switch live between **Low, Medium, High, and Ultra** to scale pixel ratio, soft PCF shadows, max agents, and smart LOD distance (75m → 220m).
- **🔊 Procedural Audio & City Radio:** 100% synthesized Web Audio API soundscape (altitude-scaled wind + traffic hum, engine pitch, dual-tone horn, thunder, sirens, plus 3 Procedural Radio Stations: *Skyline Lo-Fi*, *Neon Synthwave*, and *Ambient Metropolis*).
- **💾 Persistence & Blueprints:** Multi-city browser saves plus one-click `.json` **City Blueprint** Export & Import directly from the Title Screen and Settings menu.
